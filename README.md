# C Programming Projects

A collection of C programming projects developed while building my foundation in computer science and software development.

These projects demonstrate my understanding of core programming concepts including functions, arrays, loops, conditional logic, user input, and algorithmic problem-solving.

## Projects

### 8-Bit Decimal to Binary Converter

A C program that converts an unsigned decimal integer from 0–255 into its 8-bit binary representation.

**Concepts demonstrated:**
- Functions
- While loops
- Conditional statements
- Arithmetic operations
- User input and output

**Source:** [`binary_converter.c`](binary_converter.c)

---

### Array Search & Occurrence Counter

A C program that searches a 50-element integer array for a user-specified value and determines how many times that value occurs.

**Concepts demonstrated:**
- Arrays
- For loops
- Conditional statements
- Searching algorithms
- User input

**Source:** [`array_search.c`](array_search.c)

---

### Time-to-Seconds Converter

A C program that accepts hours, minutes, and seconds and converts the entered time into total seconds using a dedicated conversion function.

**Concepts demonstrated:**
- Functions
- Parameters and return values
- Arithmetic operations
- Variables and data types
- User input and output

**Source:** [`time_converter.c`](time_converter.c)
